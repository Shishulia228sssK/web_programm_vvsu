# Дизайн коллекции игр

Основная задача: выбрать игру и открыть её без лишнего промо. Коллекция работает на виртуальных монетах.

Используемые скиллы, закреплённые по исходным коммитам:
- Anthropic frontend-design: https://github.com/anthropics/skills/tree/ca45fc496a3436251f191354091d557da31c15b5/skills/frontend-design
- Vercel web-design-guidelines: https://github.com/vercel-labs/agent-skills/tree/1a2c79d4e6c4a2283dc2c614b6538cbe1ed5ca62/skills/web-design-guidelines

Скиллы установлены в .agents/skills для работы с этим репозиторием.

Палитра: меловой #eeeef4, чернильный #232536, кобальт #2949c7, сукно #285347, вишня #a52f46, пергамент #eae0cc.
Шрифты: Trebuchet MS для навигации и текста, Georgia для игрового заголовка и нескольких карточек, Impact/Arial Narrow для графических афиш. Системные семейства не требуют загрузки шрифтов.
Композиция: короткое приветствие слева и заметка о демо справа, затем фильтры и коллекция афиш. Всё по левому краю, кроме текста внутри некоторых афиш.
Карточки: рулетка — широкая афиша с обрезанным колесом; блэкджек — вертикальная композиция с картами; русский покер — веер; три карты — минималистичный триптих; холдем — горизонтальный стол; баккара — симметрия двух сторон; слоты — табло; crash — технический график; mines — раскрытое поле; dice — крупный куб.
Никаких выдуманных отзывов, live-статусов, декоративных номеров карточек и дублирующих плашек.

Схема:
[Логотип / Каталог История Рейтинг / Баланс Вход]
[Игры за одним столом                 [Демо: без платежей]]
[Фильтры                                         Поиск]
[     Рулетка       ][Блэкджек][Русский покер]
[Три карты][       Холдем       ][Баккара]
[       Слоты       ][       Crash        ]
[       Mines       ][       Dice         ]
[Виртуальные монеты / Условия]

Самопроверка перед реализацией: одинаковые карточки с картинкой сверху и подписью снизу отвергнуты. Общие размеры сетки сохраняют читаемость, композиция и иллюстрация каждой афиши различаются. Главный акцент — сама коллекция, отдельного большого рекламного hero нет.

Проверки: HTTP 200 и CSS MIME для всех подключённых стилей, ошибки JS, поиск и категории, клавиатура, 320/390/768/1440 px, светлая и тёмная темы, существующие игровые сценарии. Новые иллюстрации — локальный SVG внутри разметки. Оформление добавлено в существующий scene.css, серверный маршрут сохраняется.
