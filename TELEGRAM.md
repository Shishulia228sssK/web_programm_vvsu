# ЛУДКА.COM в Telegram — бесплатно, с Windows-компьютера

Бот: **@Shishulia_bot**. Сайт открывается кнопкой как Telegram Mini App. Node.js продолжает работать на вашем компьютере, Cloudflare Quick Tunnel предоставляет временный HTTPS-адрес. Аккаунт Cloudflare, домен и платный хостинг для этого варианта не нужны. Бесплатный туннель подходит для демонстрации; компьютер должен оставаться включённым и подключённым к интернету.

## Что уже подготовлено

- Интерфейс учитывает размер окна и безопасные отступы Telegram.
- Нативная кнопка «Назад» закрывает окно результата/рейтинга или возвращает к каталогу.
- Официальный Telegram SDK загружается только при запуске Mini App; обычный сайт работает без него.
- Вход остаётся по имени и паролю. Автоматического входа по Telegram нет: данные `initDataUnsafe` не используются как авторизация. Игры, баланс и сессии проверяются сервером.
- Секреты не требуются для запуска сайта. Кнопку можно настроить через BotFather без передачи токена кому-либо.

## 1. Обновите проект

В первом PowerShell откройте папку проекта, остановите старый сервер через Ctrl+C и выполните:

```powershell
cd "$env:USERPROFILE\Desktop\web_programm_vvsu-main"
git pull --ff-only
npm ci
```

Если папка скачана ZIP-архивом и `git pull` пишет «not a git repository», обновление через Git в ней недоступно. Чтобы дальше обновляться одной командой, установите Git (`winget install --id Git.Git --exact`), откройте новый PowerShell и создайте отдельную копию:

```powershell
cd "$env:USERPROFILE\Desktop"
git clone https://github.com/artem0519vb-droid/web_programm_vvsu.git ludka-telegram
cd ludka-telegram
npm ci
```

При остановленном старом сервере скопируйте папку `data` из старого проекта в `ludka-telegram`, если хотите перенести аккаунты. Дальше выполняйте команды из новой папки; старую удалять не нужно.

Нужен Node.js 22 или новее. Папку `data` не удаляйте: там аккаунты, баланс, незавершённые игры и история. Для резервной копии остановите сервер и скопируйте `data` в другую папку. Не запускайте два сервера с одной папкой данных.

## 2. Запустите сайт для HTTPS-туннеля

В этом же PowerShell:

```powershell
$env:HOST = '127.0.0.1'
$env:PORT = '3000'
$env:COOKIE_SECURE = 'true'
$env:COOKIE_SAMESITE = 'None'
npm start
```

Можно вместо этих команд запустить `scripts\start-telegram.ps1`. Если Windows запрещает запуск локальных PowerShell-скриптов, используйте команды выше — менять политику безопасности не требуется.

Оставьте терминал открытым. `Secure` защищает cookie при работе через HTTPS, а `SameSite=None` разрешает их использование во встроенном окне. Для проверки входа используйте именно HTTPS-ссылку туннеля, а не локальный HTTP-адрес.

## 3. Установите и запустите Cloudflare Tunnel

Откройте **второй PowerShell**:

```powershell
winget install --id Cloudflare.cloudflared --exact
```

После первой установки откройте второй PowerShell заново и выполните:

```powershell
cloudflared tunnel --url http://127.0.0.1:3000
```

В выводе появится адрес вида `https://some-random-name.trycloudflare.com`. Используйте свой адрес из вывода, а не этот пример. Откройте его с телефона и проверьте регистрацию/вход и одну игру. Не задавайте `--http-host-header localhost`: сервер проверяет соответствие Origin и Host.

Оба терминала должны работать. Ссылка публичная: любой, кому она известна, сможет открыть сайт и создать аккаунт. В приложении только виртуальные монеты.

## 4. Подключите кнопку в @Shishulia_bot

В Telegram откройте настоящий **@BotFather**:

1. Отправьте `/setmenubutton`.
2. Выберите **@Shishulia_bot**.
3. Укажите текст кнопки **Играть**.
4. Вставьте HTTPS-ссылку из cloudflared.
5. Откройте личный чат с @Shishulia_bot, нажмите «Старт», затем кнопку меню «Играть».

Отдельный постоянно работающий процесс бота для кнопки меню не нужен: открывается наш сайт. Если кнопка ещё не появилась, заново откройте чат. Дополнительно можно настроить Main Mini App через меню управления ботом в BotFather, следуя его текущим подсказкам; это не обязательно для кнопки меню.

### Необязательный вариант: настроить кнопку из PowerShell

Вместо BotFather доступен `scripts/telegram-menu.mjs`. Токен вводится локально, скрыто; в чат его присылать не нужно. В **третьем PowerShell** в папке проекта:

```powershell
$secret = Read-Host 'Токен бота от BotFather' -AsSecureString
$env:TELEGRAM_BOT_TOKEN = [System.Net.NetworkCredential]::new('', $secret).Password
$env:TELEGRAM_WEBAPP_URL = Read-Host 'HTTPS-ссылка из cloudflared'
node scripts/telegram-menu.mjs
Remove-Item Env:TELEGRAM_BOT_TOKEN
Remove-Variable secret
```

Скрипт делает только `setChatMenuButton`, не рассылает сообщения и не сохраняет токен в файлы. Он не нужен при ручной настройке через BotFather. Если токен случайно раскрыт, отзовите его через BotFather и получите новый.

## 5. Проверка в Telegram

- Откройте Mini App в актуальном Telegram на телефоне.
- Войдите существующим аккаунтом: прежний прогресс должен сохраниться.
- Проверьте слоты: результат появляется под барабанами, без автоматического модального окна.
- Проверьте русский покер: обмен от одной до пяти карт **либо** шестая карта; цена каждого улучшения — одно Ante.
- В баккаре один бокс с пятью видами ставок; статистика открывается отдельно.
- Проверьте рейтинг, светлую тему, прокрутку и нативную кнопку «Назад».

Реальный запуск в вашем Telegram проверяется после настройки HTTPS-ссылки и кнопки. Облачные тесты проекта проверяют интерфейс и имитируют Telegram SDK, но не заменяют этот шаг.

## Остановка, повторный запуск и обновления

Для остановки нажмите Ctrl+C в обоих терминалах. При перезапуске повторите шаги 2 и 3. Quick Tunnel обычно выдаёт **новую ссылку** — обновите кнопку через BotFather или необязательный скрипт. Аккаунты остаются в `data`, но на новом адресе потребуется войти заново.

Для обновления кода остановите Node.js, выполните `git pull --ff-only`, затем `npm ci` и снова шаг 2. Если туннель не останавливался, его адрес обычно сохраняется.

Для обычного локального запуска без туннеля откройте новый PowerShell и используйте `npm start`; по умолчанию сессии работают с `SameSite=Strict` без Secure. Если используете тот же терминал:

```powershell
Remove-Item Env:COOKIE_SECURE -ErrorAction SilentlyContinue
Remove-Item Env:COOKIE_SAMESITE -ErrorAction SilentlyContinue
npm start
```

## Если что-то не работает

- **Cloudflared не найден:** перезапустите PowerShell после установки; проверьте `cloudflared --version`.
- **502 / сайт недоступен:** проверьте первый терминал и порт 3000. Не закрывайте Node.js.
- **Кнопка ведёт на старую страницу:** обновите URL после перезапуска туннеля и снова откройте Mini App.
- **Вход пропадает:** открывайте HTTPS-адрес; проверьте `COOKIE_SECURE=true` и `COOKIE_SAMESITE=None`, затем перезапустите Node.js.
- **В веб-версии Telegram не сохраняется вход:** браузер может блокировать сторонние cookie даже с SameSite=None. Используйте нативный Telegram или открывайте сайт отдельно в браузере. Автоматический Telegram-вход с проверкой подписи — отдельная доработка.
- **Ссылка недоступна из сети телефона:** проверьте обычный браузер на телефоне. Доступность Cloudflare/Telegram зависит от сети и региона.
- **SDK недоступен:** сайт остаётся рабочим, но функции нативной кнопки и отступов могут быть недоступны до восстановления связи с telegram.org.

Не публикуйте `data`, токены, cookie и резервные копии с аккаунтами в GitHub. `.env` исключён из Git, но приложение само не загружает `.env`: используйте переменные PowerShell, как показано выше.
